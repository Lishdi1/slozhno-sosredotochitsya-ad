# Сложно сосредоточиться
 
Проектная работа — адаптивный сайт в двух цветовых темах (тёмной и светлой)
с автоматическим и ручным переключением тем.
 
## Описание
 
Одностраничный адаптивный сайт-лонгрид о том, почему сложно сосредоточиться
и как с этим бороться. Свёрстан по макету из Figma с подходом **Mobile First**.
 
Сайт поддерживает три режима темы:
 
- **День** — светлая тема;
- **Неон** — тёмная тема;
- **Авто** — тема подстраивается под системные настройки пользователя
  (`prefers-color-scheme`).
Выбранная тема запоминается между посещениями (`localStorage`).
 
## Функциональность и особенности
 
- адаптивная «резиновая» вёрстка под три брейкпоинта: 375, 768 и 1024 px;
- две цветовые темы на CSS-переменных + принудительное переключение кнопками;
- раскладка на CSS Grid, в том числе «журнальная» сетка галереи;
- адаптивный заголовок через `clamp()`;
- декоративные элементы (уголки, индикатор REC, тень заголовка) на псевдоэлементах;
- семантическая и валидная HTML-разметка, доступность (`aria`, `:focus-visible`);
- «ленивая» загрузка изображений галереи.
## Используемые технологии
 
- HTML5 (семантическая разметка)
- CSS3 (кастомные свойства, Grid, Flexbox, медиазапросы, `clamp()`,
  `prefers-color-scheme`)
- JavaScript (переключение тем)
- Шрифт IBM Plex Mono
